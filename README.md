# PoE2DB KR

패스 오브 엑자일 2 한국어 자료를 폰에서 빠르게 찾아보는 앱입니다. poe2db.tw/kr의 스킬 젬, 보조 젬, 유니크 아이템, 화폐, 전직, 키워드를 미리 받아 앱에 넣어 두고, 목록은 네이티브로 그리며 상세 페이지는 웹뷰로 엽니다.

## 화면 구성

- **DB** — 전체 4,354건. 무기·방어구·장신구·룬·화폐·유니크·스킬 젬·보조 젬·전직·키워드 칩으로 좁혀 볼 수 있습니다.
- **시세** — poe.ninja 실시간 시세 (화폐·룬·에센스·영혼 핵 등 9종 교환 품목과 고유 장비)
- **패시브** — poe2db.tw 패시브·아틀라스 트리 뷰어. PoB 빌드를 불러온 뒤에는 그 캐릭터가 찍은 노드가 황금색으로 켜진 트리를 **앱 안에서 직접** 그려 줍니다(핀치 줌·이동, 노드를 누르면 한글 설명). 같은 트리를 poe2db에서도 열 수 있습니다.
- **PoB** — 개요 / 스킬 / 장비 / 설정 / 패시브 / 전투 / 메타
- **즐겨찾기** — 별표로 저장한 항목

### 전투 시뮬레이터

PoB 탭에서 불러온 빌드의 DPS·공격 속도·치명타·생명력·보호막·방어도·회피·저항을 그대로 가져와 2D 스틱맨 전투로 돌려 봅니다.

- 16T 맵핑(10 / 25 / 50 / 100 / 200 / 300 / 500마리, 증폭 모드) 또는 우버 보스 5종(재의 중재자·크세쉬·안개 속의 왕·자로크·올로스)
- **대규모 무리는 순차 스폰** — 화면에는 최대 120마리만 세우고, 처치될 때마다 대기 중인 무리를 가장자리에서 채웁니다. 500마리도 그릴 목록이 120~150마리로 유지돼 프레임이 밀리지 않습니다.
- 메인 스킬 이름으로 이펙트를 자동 선택합니다: 얼음 화살(파편 부채꼴), 번개(연쇄 번개·낙뢰 기둥), 화염(2중 폭발 링), 근접(검기·충격파), 카오스(도트 오라), 소환수(미니언 타격).
- 스킬 칩은 `자동`(PoB 주력 스킬)과 불러온 빌드에 실제로 켜져 있는 액티브 스킬(한글명, 최대 5개)로 채웁니다. 빌드를 바꾸거나 스킬을 끄면 칩도 그 빌드에 맞게 다시 만들어집니다.
- 주력 그룹은 화면에서 고른 값이 없으면 PoB가 계산한 그룹(`mainSocketGroup`)과 그 안의 스킬 번호(`mainActiveSkill`)를 그대로 따릅니다.
- 마릿수·보스 칩과 달리 `피통·피해 증폭` 칩은 누를 때마다 켜짐/꺼짐이 뒤집힙니다(켜면 적 체력 1.8배·피해 1.4배).
- PoB가 DPS를 `inf`로 내보내는 빌드는 계산이 발산한 빌드입니다(두꺼비 폭발처럼 피해가 끝없이 되풀이되는 조합). 앱은 그 값을 4만대 추정치로 깎지 않고, poe.ninja가 보여 주는 것과 같은 **32비트 상한 2.1B**(2,147,483,647)로 표시합니다. 나머지 스킬은 평균 타격·공속·치명타에서 출발한 제 몫(보조 젬 수·젬 레벨·다단 히트 반영)으로 따로 잡아, 주력이 2.1B인 동안 다른 스킬은 10k·5.8k·1.6k처럼 수천~수만 대에 머뭅니다. 값이 추정이면 화면에 그렇게 적고, 10억 이상 수치는 `2.1B`처럼 B 단위로 표시합니다.
- 주력 스킬은 PoB `mainSocketGroup`·`mainActiveSkill`을 따르되, 그 그룹에 도이드리의 파멸이 들어 있으면 실제 피해 스킬인 **암울한 결과**로 잡습니다.
- 공격 속도에 맞춘 공격 모션, 치명타 화면 흔들림과 `CRIT!` 숫자, 처치 파편, 적 처치/사망 시 결과 요약(소요 시간·가한 피해·실전 DPS·치명타·피격/회피·생존율)
- 점멸 타격·질풍·충전 지팡이처럼 적에게 붙는 순간이동 근접기는 걸어가지 않고, 공격할 때마다 적 옆으로 텔레포트해 벱니다. 지나온 자리에 푸른·금빛 잔상 2~3개와 섬광 선이 남습니다.
- 초당 4회를 넘는 고속 공속은 한 프레임에 여러 타를 누적해 타격이 씹히지 않고, 베기 궤적도 2~3겹으로 겹쳐 그립니다. (초당 30회까지 반영)
- 전투 중 1배속/2배속, 일시정지, 초기화

#### 인게임 스킬 모션

스킬 젬 이름으로 모션을 알아보고, 그 스킬만의 회전·투사체·소환물로 그립니다. 한글 이름과 영문 이름을 모두 받습니다.

| 스킬 | 전투에서 하는 일 |
|---|---|
| 선회 공격 | 캐릭터가 빙글빙글 돌며 적 쪽으로 전진하고, 회전마다 사방을 벱니다(다단 히트·회전 궤적) |
| 소용돌이 베기 | 크게 휘돌러 **와류**를 남깁니다. 같은 자리에 다시 쓰면 와류가 단계를 올려 커지고, 적을 감속·실명시킵니다 |
| 돌개바람 | 와류를 먹어 증폭된 돌개바람을 여럿 띄웁니다. 돌개바람은 흔들리며 전진하고 휘말린 적을 반복해서 벱니다 |
| 폭풍의 종 | 주력기로 **연계 4**를 채워야 종이 떨어집니다. 종을 다시 때리면 충격파가 터집니다(최대 3개) |
| 전기불꽃 | 마법봉을 채찍처럼 튕기면 **나선 두 겹으로 18발**(20레벨 9발 × 2, 추가 투사체만큼 더)이 360도 사방으로 퍼집니다. 줄기마다 지그재그로 기어가며 적을 관통하고 벽에서 세 번 튕기며, 2초 동안 살아 화면 전체를 번개로 채웁니다 |
| 번개 화살 | 화살이 꽂히면 주변 적에게 연쇄 번개가 뻗습니다 |
| 얼음 화살 | 명중 지점에서 부채꼴로 얼음 파편이 흩어집니다 |
| 혜성 | 하늘에서 얼음 덩어리가 떨어지고, 시전자는 뒤로 도약합니다 |
| 화염구 | 충돌하면 폭발하며 불티 고리가 퍼집니다 |
| 폭발 유탄 | 대상 지점까지 굴러가 멈춘 뒤 퓨즈가 타면 터집니다 |
| 살상 장법 | 적에게 질주해 마무리 타격하고 권능 충전을 챙깁니다 |
| 회오리 사격 | 화살이 떨어진 자리에 회오리가 섭니다 |
| 기름 포화 | 와이번으로 변신해 기름을 세 갈래로 순차 발사하고, 떨어진 자리에 기름 지대를 남깁니다. 권능 충전이 있으면 태워 집중을 유지하며 전기를 띤 기름을 계속 뿌립니다 |
| 기름 유탄 | 낮게 굴려 터뜨려 기름 지대를 만듭니다. 점화·폭발이 닿으면 기름에 불이 붙어 계속 탑니다 |
| 연발 사격 | 시위를 빠르게 당겼다 놓으며 화살을 몰아 쏩니다 |

| 서리 폭탄 | 맥동하는 보주가 0.9초마다 주변 적을 노출시키고, 4초 뒤 기폭하며 냉기 피해를 줍니다 |

| 야수 스킬 | 곰·늑대인간·와이번 형상의 기본 공격과 포효를 앞발·턱·날개 동작으로 냅니다 |

#### 관절 애니메이션

스틱맨은 막대기 하나가 아니라 **머리·몸통·상완/전완·허벅지/종아리·무기**를 따로 꺾는 관절 캐릭터입니다. `SkillPoses.kt`가 스킬마다 시전 키프레임을 들고 있어, 같은 근접기라도 동작이 다릅니다.

- 소용돌이 베기: 몸을 낮춰 크게 감아 돌며 360도로 벱니다 (몸통 회전 + 세 겹 검기)
- 돌개바람: 두 팔을 머리 위로 모아 내려친 뒤 크게 휘돌립니다
- 전기불꽃: 마법봉을 뒤로 눕혔다가 세 번 채찍처럼 튕깁니다
- 혜성: 두 손을 하늘로 치켜들었다가 땅으로 내리꽂고, 몸이 깊게 앉습니다
- 활 스킬: 시위를 눈까지 당겼다 놓고, 놓는 순간 뒷팔이 뒤로 빠집니다
- 저주·함성: 두 팔을 벌리고 고개를 젖힙니다

시전 초반에는 키프레임을 거의 그대로 쓰고, 막바지에만 서 있는 자세로 돌아가 동작이 뭉개지지 않습니다. 다리도 허벅지·종아리로 나뉘어 무릎이 꺾이므로, 앉아서 힘을 모으는 자세가 일직선으로 무너지지 않습니다.

- 공허의 형상: 근접기를 쓸 때마다 **반투명 보랏빛 상**이 플레이어 주위에 나타나, 그 스킬을 한 번 휘두르고 사라집니다. 상은 공허의 형상에 넣은 스킬을 그대로 따라 하며(예: 선회 공격), 권능 충전을 하나 쓰면 한 번에 3개가 나옵니다.
- 공허의 집중: 몇 초마다 실체 없는 종이 플레이어 주위에 생기고, 때리면 충격파가 터지며 권능 충전을 돌려줍니다.
- 전장 HUD에 지금 봇이 돌리는 콤보(예: `봇 소용돌이 베기 · 와류 2단계 → 돌개바람 · 와류 2단계 · 돌개바람 2`)가 한 줄로 표시되고, 결과 요약에는 상·와류·돌개바람·종 횟수가 같이 적힙니다.

#### 준비 단계 콤보 봇

빌드에 같이 들어 있는 액티브 스킬을 읽어, 준비가 필요한 조합이면 **봇이 스스로 순서를 짜서** 돌립니다. 전투 시작 전 화면에 `봇 콤보: …`로 순서를 미리 보여 줍니다.

| 빌드에 있으면 | 봇이 도는 순서 |
|---|---|
| 소용돌이 베기 + 돌개바람 | 소용돌이 베기 2회(와류 2단계) → 돌개바람 |
| 폭풍의 종 | 주력기 4회(연계 4) → 폭풍의 종 → 주력기 2회(종 울리기) |
| 저주·징표 | 저주 → 주력기 |
| 살상 장법 + 권능 충전 소모기(점멸 타격 등) | 살상 장법 → 주력기 |

- 연계가 모자라면 종을 떨어뜨리지 못하고, 그동안 주력기로 연계를 채웁니다
- 와류가 없으면 돌개바람도 그냥 나가지만, 와류를 먹인 쪽이 피해가 더 큽니다

#### 콤보 설정

전투 탭의 **콤보 설정** 버튼을 누르면 시트가 열리고, 빌드에 장착된 스킬을 눌러 원하는 순서를 쌓을 수 있습니다.

- 목록에는 **빌드에 든 액티브·발동 스킬이 보조 젬만 빠진 채 전부** 나옵니다. 다른 스킬 세트에서 꺼 둔 그룹, 패시브 트리(공허의 형상 등)와 아이템(목걸이·부적의 부여 스킬)이 준 스킬, 아이템 설명에만 적힌 `Grants Skill`까지 포함합니다
- 같은 스킬을 여러 번 넣을 수 있습니다 (예: 소용돌이 베기 ×3 → 연발 사격 → 돌개바람)
- ↑ ↓ 로 순서를 바꾸고 ✕ 로 빼며, **자동 추천**은 빌드에 맞는 준비→마무리 순서를 채워 줍니다
- 설정한 콤보는 기기에 저장되고, 전투 화면 위에 `직접 설정한 콤보: …`로, 전장 아래에 칩으로 표시됩니다. 지금 서 있는 칸만 밝게 켜집니다
- 봇은 설정한 순서를 그대로 돌립니다. 폭풍의 종처럼 연계가 모자란 칸은 그 자리에서 기다리며 주력기로 연계를 채우고, 준비가 끝나면 다시 그 칸부터 이어 갑니다

#### 부적 변신과 기름 포화

PoE2에서 부적은 힘·지능을 요구하는 양손 근접 무기이고, 부적을 들고 있는 동안에는 그 형상(곰·늑대인간·와이번)으로 변신한 상태가 됩니다. 형상마다 쓸 수 있는 형태 변환 스킬이 다릅니다.

- 빌드의 무기 슬롯에 부적이 있거나, 형태 변환 스킬(기름 포화·사나운 발톱·십자 베기 등)이 주력이면 `Beasts.kt`가 형상을 판정합니다
- 전투가 시작되면 형상 오라가 터지고 스틱맨이 해당 야수로 변합니다. 곰은 앞발·턱·갈기, 늑대인간은 굽은 허리와 발톱·꼬리, 와이번은 날개·긴 목·꼬리를 관절로 움직입니다
- 기름 포화는 와이번으로 기름을 순차 발사해 기름 지대를 만들고, 기름 지대는 적을 20% 늦추고 노출(총 원소 저항 -20%)시킵니다. 점화된 적이나 폭발이 닿으면 불이 붙어 계속 타오릅니다
- 결과 요약에 변신 형상·기름 지대·점화 횟수·기름 피해가 함께 적힙니다

### 우버 보스 패턴

보스마다 인게임에서 쓰는 대표 스킬을 자기 패턴으로 씁니다. 체력 50% 이하에서 2페이즈로 넘어가고, 패턴이 강화됩니다.

| 보스 | 1페이즈 | 2페이즈 |
|---|---|---|
| 재의 중재자 | 화염 검기(직선 예고), 불기둥 | 심판의 안전지대(전장 폭발·가운데만 안전), 유성 낙하 |
| 균열 군주 크세쉬 | 균열 구체 연사, 거대 손 내려찍기 | 균열 쫄 소환 |
| 안개 속의 왕 | 의식 투사체, 순간이동 | 저주 장판(가운데만 안전한 고리), 분신 |
| 올로스 | 룬 검기, 빙결 파편 | 룬 보호막(피해 흡수), 광역 냉기 폭발 |
| 자로크 | 시간 구체, 모래시계(십자 예고) | 시간 왜곡, 번개 구슬 회전 |

- 스킬이 떨어지기 전에 바닥에 경고 장판(원·직선·고리·십자)이 차오르고, 안에 있으면 방어력·저항·회피로 계산한 실제 피해를 받습니다
- 플레이어는 장판이 떨어지기 직전 구르기로 빠져나갑니다
- 전장 HUD에 `P1/P2`와 지금 쓰는 패턴 이름이 표시됩니다
- 보스 5종은 각자의 실루엣(화염 후광·균열 팔·사슴뿔·룬 방패·모래시계)으로 그려집니다.
- 잔몹은 **검은 외곽선을 두른 괴물 실루엣**으로 다시 그렸습니다. 일반은 앞으로 굽은 뿔 달린 짐승, 마법은 떠 있는 후드 술사(보랏빛 눈·지팡이), 희귀는 날개·등 가시·갑주를 두른 거구(황금 왕관·오라)입니다. 눈은 붉거나 보랏빛으로 빛나 플레이어(밝은 뼈대)·소환수(뼈/유령)·반려수(네 발 짐승)와 한눈에 구분됩니다.

### 소환수 · 반려수

빌드에 소환수 젬이 있으면 전투에 실제로 세워 적을 쫓아가 때립니다.

- **해골 계열** — 전사·저격수·방화범·서리/폭풍 마법사·돌격병·강탈자·성직자. 부활하는 언데드라 죽으면 5초 뒤 다시 일어나고, 성직자는 주변 소환수를 고칩니다.
- **좀비·격노의 유령·망령** — 좀비는 20초 지속, 격노의 유령은 적이 지나쳐 가는 대신 빠르게 달려듭니다.
- **반려수** — 길들인 야수, 늑대 무리, 하이에나, 연무의 큰까마귀, 지옥불 사냥개, 야생 보호자(곰), 아즈메리 늑대, 로아. 네 발 짐승 실루엣과 금빛 목걸이로 소환수·몬스터와 구분됩니다.
- **정신력 점유** — 젬에 적힌 점유량을 합산해 `Spirit` 예산을 넘으면 마릿수를 줄이고 그 이유를 전투 탭에 적습니다.
- **어그로·피해 분담** — 적은 가까운 소환수를 72% 확률로 노리고, 근접·원거리 공격과 보스 광역기가 소환수에게도 들어갑니다.
- **소환수 사망 시 시전** — 소환수가 쓰러질 때마다 메타 에너지가 차서 연결된 주문이 발동합니다.
- 주력 스킬이 소환수 젬이면 PoB가 계산한 DPS를 소환수들이 나눠 갖고, 플레이어는 지원 동작만 합니다. 두꺼비처럼 다른 개체가 피해를 내는 빌드에서는 플레이어 평타 DPS를 따로 잡아 두 번 세지 않습니다.

### 암울한 결과 (Dark Consequences)

도이드리의 파멸(혈통 보조 젬)이 붙은 저주는 저주받은 지대를 만들고, 그 지대에서 0.25초마다 **마녀두꺼비**가 나옵니다(지대 하나에 4마리, 지대 2개까지).

- 두꺼비가 적에게 도약해 명중하면 **암울한 결과**가 발동해 1.6미터 폭발(카오스 피해)이 터집니다. 피해는 보조 대상 저주 젬의 레벨을 따릅니다(1레벨 5~10, 20레벨 186~345, 40레벨 3,246~6,029).
- PoB는 이 스킬의 DPS를 `inf`로 내보냅니다. 앱은 poe.ninja와 같이 그 값을 표시 상한 **2.1B**로 잡고, 전장에 저주받은 지대와 두꺼비를 그려 실제로 폭발시키며 폭발 횟수·피해를 결과에 적습니다. 두꺼비 한 번의 폭발 피해도 상한에 맞춰 커져서 16T 무리와 우버 보스가 한두 번의 폭발에 정리됩니다.
- PoB가 유한한 값을 주는 빌드에서는 `AverageHit`과 두꺼비 수·도약 주기로 초당 폭발 수를 어림합니다.
- 전투 탭 스킬 칩 맨 앞에 `암울한 결과`가 뜨고, 두꺼비 폭발은 소환수 피해로 따로 집계됩니다.

### 고유 아이템 효과

장착한 고유 아이템의 옵션 중 단일 타격 계산에 드러나지 않는 것을 `UniqueEffects.kt`가 읽어 전투에 넣습니다.

- 추가 투사체·연쇄, 피해의 일부를 다른 속성으로 얻기(`Gain 12% of Damage as Extra Fire Damage`), 명중 시 저주, 마무리 타격
- 처치 시 충전, 희귀 몬스터 처치 시 그 옵션 획득(헤드헌터), 주기적 성소 버프(신념의 망치), 재생
- 소환수 피해·생명력, 정신력, 접근 범위 2배
- 전투 탭에 `고유 효과 N개 · 아이템 이름…`과 대표 효과 3줄이 뜨고, 결과 요약에는 반영된 효과가 함께 남습니다.
- 생명력·저항·공격 속도처럼 PoB가 이미 계산한 수치는 다시 더하지 않고 목록에만 적습니다.

### 메타젬

PoB 2 빌드에 들어 있는 메타젬을 **전부** 인식해 전투에서 동시에 굴립니다. 첫 그룹만 쓰지 않습니다.

- 치명타 시 시전 · 감전 시 시전 · 빙결 시 시전 · 점화 시 시전 · 원소 상태이상 시 시전 · 원소 기원 · 소환수 사망 시 시전 · 피격 시 시전 · 기절 시 시전 · 회피 시 시전 · 근접 처치 시 시전
- 전령 4종(천둥·얼음·재·역병)과 신성모독
- 영문 이름·한글 이름·PoB `skillId` 모두로 판별합니다
- 적중할 때마다 치명타·감전·빙결·점화·처치·피격·회피 사건을 실제로 판정해 각 메타젬의 에너지를 채우고, 가득 차면 연결된 스킬(Comet·Arc·Fireball·Frost Bomb 등)이 이펙트와 피해로 발동합니다
- 전장 HUD와 결과 요약에 메타젬별 발동 횟수·피해량을 표시합니다

### 전직 패시브

PoB 빌드에 찍힌 전직 노드를 poe2db 트리 자료에서 찾아, 옵션을 두 갈래로 나눠 씁니다.

- **전투에 직접 반영** — 부여 스킬(공허의 형상·공허의 집중 등), 추가 투사체, 상태이상 확률·강도, 받는 피해 감폭과 물리 피해의 원소 전환, 보호막 재충전 지연·속도, 생명력 재생·흡수, 효과 범위, 메타 에너지
- 공허의 형상은 집중 유지가 아니라 **근접 공격에 반응**합니다. 플레이어가 근접기를 쓸 때마다 플레이어 주위 6미터 안에 상이 나타나, 형상에 넣은 근접기를 한 번 휘두르고 사라집니다. 상의 피해는 그 스킬의 80%이고, 권능 충전을 하나 쓰면 상이 2개 더 생깁니다(최대 3개).
- 공허의 집중은 노드에 적힌 대로 3초(재사용 대기시간 회복 반영)마다 종을 띄우고, 종을 때리면 충격파가 터지며 권능 충전이 돌아옵니다
- **PoB 수치에 이미 포함** — 생명력·에너지 보호막·방어도·회피·저항·치명타처럼 PoB가 계산해 넘긴 값은 다시 더하지 않고 목록에만 적습니다
- 전투 탭 머리말에 `전직 효과 N개 적용 · 주요 노드…`와 `전투 반영 N개`가 뜨고, 전장 HUD에도 금색 줄로 표시됩니다
- 전직별 노드 분석표는 `docs/ascendancy-effects.md`에 있습니다(전직 36종·노드 669개, 2026-11-23 자료)

수치는 PoB 기준값에 재생·보호막 충전·회피를 일반적인 값으로 가정한 간이 시각 시뮬레이션이며 실제 게임 판정과 다릅니다.

검색창은 이름, 영문 이름, 태그, 설명을 한 번에 훑습니다. 카드를 누르면 상세 웹뷰가 열리고, 웹뷰에는 모바일용 CSS를 넣어 상단 메뉴와 배너를 걷어 내고 넓은 표를 가로 스크롤로 감쌉니다.

### 메타 랭킹

PoB 탭의 **메타** 페이지는 리그 전직 점유율과 인기 빌드 DPS를 스냅샷으로 보여 줍니다.
poe.ninja 빌드 통계는 공개 API가 아니라 앱이 직접 받아오지 않고, U4N 티어리스트·PoB Archives에
공개된 값을 `Meta.kt`에 옮겨 두고 화면에 출처와 기준일을 함께 적습니다.
전직·스킬 이름은 게임 한국어 표기(poe2db.tw/kr)로 적고, DPS는 만 단위로 읽습니다.
poe.ninja 빌드 랭킹은 같은 페이지의 버튼으로 앱 안에서 실시간으로 열 수 있습니다.

### 장비창 (PoE2 인벤토리)

PoB 탭의 **장비** 페이지는 리스트 대신 게임과 같은 자리에 슬롯을 놓은 장비창입니다.

```
       [  투구  ] [목걸이]
[무기 1] [  갑옷  ] [무기 2]
[반지 1] [ 허리띠 ] [반지 2]
[ 장갑 ]           [ 장화 ]
```

- 각 칸에 아이템 아이콘을 깔고 등급(일반·마법·희귀·고유)에 맞춰 테두리 색을 바꿉니다.
- 아이콘을 한 번 탭하면 그 아이템의 이름·등급·베이스·옵션 패널이 격자 아래에 열리고,
  **같은 아이콘을 다시 탭하면 닫힙니다**. 다른 칸을 탭하면 그 칸 정보로 바뀝니다.
- 패널의 `장비 바꾸기`는 유니크 아이템을 검색해 그 슬롯에 끼우고, `초기화`는 원래 아이템으로 되돌립니다.
- 격자 아래에는 무기 교체·반지 3·부적·플라스크를 작은 칸으로 붙입니다.

## 빌드

JDK 17과 Android SDK 35가 필요합니다.

```bash
./gradlew assembleDebug      # app/build/outputs/apk/debug/app-debug.apk
./gradlew bundleRelease      # app/build/outputs/bundle/release/app-release.aab
```

`local.properties`에 SDK 경로를 적어 둡니다.

```properties
sdk.dir=/path/to/android-sdk
```

업로드 키는 `keystore/poe2db-upload.jks`에 있고, 루트의 `keystore.properties`를 읽어 서명합니다(둘 다 git 제외).
키가 없으면 릴리스 빌드는 디버그 키로 서명해 빌드만 통과시키므로, 배포 전에는 `scripts/create-release-keystore.md`를 확인하세요.

```bash
./gradlew bundleRelease
jarsigner -verify app/build/outputs/bundle/release/app-release.aab
```

스토어에 올릴 산출물은 `dist/`에 모아 둡니다.

```bash
dist/poe2db-kr-1.0.0-release-signed.aab   # 업로드 키로 서명한 AAB
dist/poe2db-kr-1.0.0-debug.apk            # 기기에 설치해 볼 APK
```

## 데이터 갱신

수록 자료는 `app/src/main/assets/poe2db_kr.json`에 들어 있습니다. 게임 패치로 수치가 바뀌면 다시 긁어서 앱을 새로 올립니다.

```bash
python3 scripts/fetch_poe2db.py        # poe2db.tw/kr 파싱 → assets JSON
python3 scripts/fetch_poe2_i18n.py     # 시세·장비 한글 사전 → assets/poe2_kr_i18n.json
python3 scripts/fetch_poe2_gems.py     # 스킬·보조 젬 한글 이름 → assets/poe2_kr_i18n.json
python3 scripts/fetch_poe2_tree.py     # 패시브 트리 노드·직업 이름·전직 부여 스킬 → assets/poe2_tree_kr.json
python3 scripts/make_ascendancy_doc.py # 전직 노드 분석표 → docs/ascendancy-effects.md
python3 scripts/make_store_assets.py   # 아이콘, 스토어 그래픽
python3 scripts/make_store_screenshots.py  # 스토어 스크린샷 5장
```

`fetch_poe2_i18n.py`는 poe.ninja 시세 응답의 영문 이름·옵션과 poe2db 한국어 페이지를 대조해
한글 이름 4,700여 개, 베이스 1,790여 개, 아이콘 3,880여 개, 옵션 문장 틀 1,880여 개를 만듭니다.
장비 옵션은 poe2db 분류 페이지(Modifiers Calc)의 영문판·한글판을 줄마다 짝지어 접사·에센스·
훼손·타락·룬·결속 문장을 모두 담고, 그 표에 없는 고유·플라스크·호신부 옵션은 고유 아이템
페이지의 두 언어 옵션을 대조해 채웁니다. `props`/`tags` 항목은 품질·방어도·요구 사항 같은
아이템 머리말과 `(implicit)`·`(crafted)` 꼬리표의 한글 표기입니다.
패치로 신규 아이템이 늘면 다시 돌려 사전을 갱신하세요 (`.cache/i18n/` 캐시).

`fetch_poe2_gems.py`는 poe2db의 스킬 젬·보조 젬·Spirit Gems 목록을 영문판·한국어판으로 짝지어
젬 이름 사전(1,060여 종)을 `poe2_kr_i18n.json`의 `gems`에 넣습니다. 지금 목록에 없는 예전 이름
(`Martial Tempo`, `Scattershot` 등 0.1 시절 보조 젬)은 웨이백 머신 사본에서 보탭니다.

`fetch_poe2_tree.py`는 poe2db 패시브 트리 자료(`data_kr.json`/`data_us.json`)에서 직업·전직 이름,
모든 노드의 한글 이름·설명·좌표, 연결선을 추려 700KB 남짓으로 만듭니다.
앱은 이 파일로 트리를 직접 그리고, PoB의 `Spec nodes` 목록을 poe2db 트리 주소로도 바꿉니다.

`fetch_poe2db.py`는 lxml만 있으면 됩니다. 내려받은 페이지는 `.cache/poe2db/`에 남아 다음 실행 때는 목록 페이지만 다시 받습니다. 젬 설명은 젬별 툴팁 조각을 한 번씩 더 받아 채웁니다.

## 배포

릴리스 AAB는 로컬에서 서명해 플레이스토어 콘솔에 직접 올립니다.

```bash
./gradlew bundleRelease
cp app/build/outputs/bundle/release/app-release.aab dist/poe2db-kr-1.0.0-release-signed.aab
jarsigner -verify dist/poe2db-kr-1.0.0-release-signed.aab
```

`versionCode`는 업로드할 때마다 `app/build.gradle.kts`에서 1씩 올립니다.
업로드 키와 비밀번호는 `keystore/`(git 제외)에만 두고, 저장소나 이슈에 적지 않습니다.
GitHub Actions로 빌드하려면 같은 값을 저장소 시크릿 `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`,
`KEY_ALIAS`, `KEY_PASSWORD`로 넣으면 됩니다.

## 고지

poe2db.tw와 Grinding Gear Games가 만든 공식 앱이 아닙니다. 게임 자료와 이미지의 권리는 원저작자에게 있고, 이 앱은 열람을 돕는 목적으로만 배포합니다. 삭제 요청이 오면 해당 자료를 내립니다.

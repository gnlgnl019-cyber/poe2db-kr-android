# PoE2DB KR

패스 오브 엑자일 2 한국어 자료를 폰에서 빠르게 찾아보는 앱입니다. poe2db.tw/kr의 스킬 젬, 보조 젬, 유니크 아이템, 화폐, 전직, 키워드를 미리 받아 앱에 넣어 두고, 목록은 네이티브로 그리며 상세 페이지는 웹뷰로 엽니다.

## v1.1.5 (versionCode 7)

- **패시브 트리 확대·축소가 제대로 되게** — 두 손가락을 벌리거나 오므리면 손가락 사이를 중심으로 확대·축소되고, 한 손가락으로 끌면 트리가 따라 움직입니다. 확대·축소 한도를 화면 크기와 트리 자리에서 계산해 잡습니다(실제 자료로 1080x1800 화면에서 0.02배~1.5배, 약 75배 범위). 이전에는 `fit()`이 최대 배율을 1.2로 못 박고 최소 배율을 마지막 화면 맞춤값의 0.6배로 잡아서, 화면 맞춤을 한 번도 하지 않은 패시브 탭에서는 0.765배에서 0.6배까지만 줄일 수 있어 축소가 거의 먹지 않았습니다. 이제 배율 한도가 뒤집혀도(최소>최대) 예외가 나지 않고, 배율·이동은 늘 한도 안에서 붙잡힙니다.
- **손짓 계산을 화면과 떼어 냄** — 손가락 자리만 받아 확대·이동·누르기를 세는 `TreeGestures`를 따로 두었습니다. 두 손가락이 닿는 순간부터 화면을 감싼 쪽이 손짓을 가져가지 않게 막고(`requestDisallowInterceptTouchEvent`를 `ACTION_POINTER_DOWN`에서도), 두 손가락 만진 뒤에는 노드가 눌리지 않게 했습니다. 손가락 하나를 뗄 때 남은 손가락 자리에서 다시 재어 트리가 튀던 문제도 없앴습니다. 기기 없이 도는 단위 시험 13개로 확대·축소·이동·누르기·경계를 확인합니다.
- **PoB 탭 패시브 화면에도 트리** — PoB 탭 `패시브`에 요약 글과 노드 목록만 있던 자리에 앱이 그리는 트리를 넣었습니다. 불러온 빌드의 직업·전직·찍은 노드가 그대로 뜨고, 그 자리에서 두 손가락 확대·축소와 한 손가락 이동이 되며 노드를 누르면 이름·상태·설명이 트리 아래에 뜹니다. 찍고 빼는 것은 트리 탭 한 곳에서만 합니다(같은 빌드를 두 화면에서 따로 찍으면 어느 쪽이 맞는지 알 수 없어서). 노드 목록은 그대로 아래에 남아 있습니다.
- **스크롤이 트리 손짓을 가져가지 않는지 시험으로 고정** — 두 화면 모두 트리 캔버스 위에 스크롤이 겹쳐 있지 않은 것을 레이아웃 그대로 확인합니다.

## v1.1.4 (versionCode 6)

- **전투 탭 위쪽 수치 요약 삭제** — 전투 탭 맨 위에 늘어서던 `폭풍의 질풍 · 연쇄 번개 · 초당 8.63회 · DPS …` 요약, 메타젬·전직 효과·고유 효과 줄을 모두 걷어냈습니다. 그 자리에서 스킬이 자동으로 정해지거나 고른 스킬을 덮어쓰던 길도 없앴습니다. 이제 `메인 스킬 선택`에서 고른 스킬 하나가 그대로 시뮬에 쓰이고, 화면에는 그 스킬 칩만 남습니다.
- **클리어·사망은 짧은 결과 화면만** — 전투가 끝나면 어두운 막 위에 **클리어!** / **사망** 과 한 줄(`적을 모두 처치했습니다` / `캐릭터가 쓰러졌습니다`)만 크게 띄웁니다. 스킬별 DPS 표·누적 피해·비율·전투 시간 같은 수치는 결과 화면에서 뺐고, HUD와 겹쳐 글자가 엉키던 문제도 사라졌습니다. 아무 곳이나 누르면 닫힙니다.
- **패시브 노드를 poe2db와 같은 크기·모양으로** — 노드 반지름을 poe2db 트리 화면이 쓰는 값 그대로 줄였습니다(테두리 51 · 주요 76 · 키스톤 109, 아이콘 34 · 49 · 69). 이전 값(108·158·196)은 노드 사이 간격보다 커서 이웃 노드를 덮었습니다. 아이콘 원은 자료에서 가장 좁은 두 노드(100.9)에서도 닿지 않고, 테두리는 가는 고리로만 둘러 이웃을 가리지 않습니다. 숙련 노드는 주요 노드 위에 겹쳐 그리지 않습니다.
- **패시브 탭 맨 위 직업 선택** — 패시브 탭 맨 위에 12직업 줄을 고정으로 두었습니다(트리 화면 위쪽에도 같은 줄). 직업을 고르면 그 직업의 시작 노드로 화면이 당겨지고, 그 노드에서 이어진 패시브를 눌러 찍고 되돌릴 수 있습니다. PoB 빌드를 불러온 직업을 고르면 그 빌드의 찍힌 노드가 그대로 열리고, 다른 직업을 고르면 그 직업 시작점에서 새로 찍습니다(찍은 노드는 직업을 바꿀 때 그 직업 시작점만 남기고 비웁니다). 이어지지 않은 노드를 누르면 왜 안 찍히는지 알려 줍니다.

## v1.1.3 (versionCode 5)

- **패시브 탭을 앱 안 트리로 다시 설계** — poe2db 화면을 웹뷰로 띄우던 길을 패시브 탭에서 **완전히 걷어냈습니다**. 빌드를 불러오지 않았을 때도 사이트 화면 대신 직업 시작점 둘레의 실제 노드를 앱이 직접 그립니다. 노드·연결선·아이콘은 assets의 자료(`poe2_tree_kr.json`, `tree_icons.webp`)만 씁니다.
- **캐릭터 주변 동그라미 제거** — 트리 한가운데의 회색 원판, 금색 고리, 전직 노드를 둘레에 두르던 8개 동그라미, 동심원 장식을 모두 지웠습니다. 직업 시작점은 이름표가 붙은 노드 하나로만 표시합니다.
- **노드가 실제로 보이게** — 노드 반지름을 좌표 간격에 맞춰 키우고(보통 108 · 주요 158 · 키스톤 196), 화면 맞춤은 찍은 노드(전직 바깥 동그라미 제외)와 시작점에 맞춥니다. 기본 화면에서 보통 노드가 반지름 8px 안팎으로 그려져 아이콘이 보입니다. `전체 보기` 단추로 트리 전체를 점 지도처럼 볼 수 있습니다.
- **메인 스킬 선택** — 전투 탭 위쪽에 「메인 스킬 선택」 줄을 두고, 불러온 빌드의 액티브 스킬 중 하나를 고르면 **그 스킬 하나로만** 싸웁니다. 봇이 다른 스킬을 알아서 섞어 쓰던 동작을 없앴습니다. 전령·정신력 버프·메타(발동) 젬은 켜 둔 것만 따로 작동합니다.
- **콤보는 직접 짠 것만** — 콤보 설정이 비어 있으면 메인 스킬만 쓰고, 사용자가 순서를 직접 쌓았을 때만 그 순서를 돕니다. 자동 추천으로 콤보를 채우던 기능은 뺐습니다.

## v1.1.2 (versionCode 4)

- **패시브 트리가 멈추던 문제** — 그리다 `IndexOutOfBoundsException`이 나면 poe2db 웹 화면으로 넘어가 사이트의 직업 선택창이 떠 있던 것을 고쳤습니다. 이제 화면에 그릴 노드·연결선을 고르는 계산(`TreeCull`)을 그리기와 떼어 두고 배열 범위를 모두 막아 두어, 어떤 배율·위치에서도 예외가 나지 않습니다. 한 조각이 실패해도 나머지는 그대로 그리고, 트리를 poe2db로 넘기지 않습니다.
- **상단 직업 선택 줄 고정** — 트리를 그리기 전에 직업·전직 줄을 먼저 채워, 포인트·정신력 계산이 실패해도 줄이 사라지지 않습니다.
- **정신력 점유 스킬 전수 반영** — poe2db의 Skill/Support/Spirit Gems 1,057쪽을 훑어 정신력을 점유하는 스킬 **149종**(정신력 젬 128 · 메타 젬 21)을 `poe2_spirit_kr.json`에 담았습니다. 점유량은 젬 페이지의 `점유: N 정신력`, 효과 수치는 효과 문장에서 읽어 방어·공격 수치에 반영합니다.
- **정신력 젬과 메타 젬 구분** — 정신력 젬은 지속 버프(수치 반영), 메타 젬은 정신력을 점유하고 조건에 맞춰 에너지를 모아 장착한 스킬을 발동하는 장치로 갈라 기록합니다. 전투 화면에서 정신력 젬·메타 젬·전령을 하나씩 켜고 끌 수 있고, 끄면 점유·버프 수치·발동·전령 피해가 모두 빠집니다(전령은 발동 목록에서 빼 두 번 집계되지 않게 했습니다).
- **콤보 설정 손가락 조작** — 스킬 버튼·`▲▼✕`·도구 버튼을 44~48dp로 키우고 누르는 동안 살짝 줄어드는 표시를 넣었습니다.
- **전면 광고** — PoB 빌드 코드로 `불러오기`를 누를 때 한 번(2분 쿨타임). 광고가 없거나 실패하면 기다리지 않고 바로 빌드를 엽니다. debug 빌드는 구글 시험용 광고 단위만 씁니다.

## 화면 구성

- **DB** — 전체 4,354건. 무기·방어구·장신구·룬·화폐·유니크·스킬 젬·보조 젬·전직·키워드 칩으로 좁혀 볼 수 있습니다.
- **시세** — poe.ninja 실시간 시세 (화폐·룬·에센스·영혼 핵 등 9종 교환 품목과 고유 장비)
- **패시브** — 패시브·아틀라스 트리를 **앱 안에서 직접** 그립니다. PoB 빌드를 불러오면 그 캐릭터의 직업·전직과 찍은 노드가 그대로 켜진 채로 열립니다. 노드에는 poe2db의 실제 패시브 아이콘이 들어가고, 트리 한가운데에는 아무 장식도 두지 않습니다(직업 시작점만 이름표가 붙은 노드 하나). 노드 크기와 테두리·아이콘 비율은 poe2db 트리 화면과 같아 이웃 노드를 가리지 않습니다. 위쪽에는 `패시브 20 / 123 · 전직 2 / 8 · 정신력 90 / 130` 카운터가 있고, 그 아래에 직업·전직을 고르는 줄이 늘 고정으로 놓입니다(12직업과 전직, 패시브 탭 맨 위에도 같은 줄). 직업을 고르면 그 시작 노드로 화면이 당겨집니다. 확대·축소는 두 손가락 핀치와 한 손가락 이동으로만 하며, 화면을 가리던 오른쪽 아래 버튼은 두지 않습니다(빌드에서 불러온 상태로 되돌리기는 위쪽 새로고침). 이어진 노드를 눌러 직접 찍거나 되돌릴 수 있고, 노드 이름으로 찾아 이동할 수 있습니다. 같은 트리를 poe2db에서도 열 수 있습니다.

- **아틀라스 트리** — 노드 575개·연결선 586개·총 123포인트를 같은 화면으로 그립니다(assets/poe2_atlas_kr.json).

### 전투 시뮬레이터

PoB 탭에서 불러온 빌드의 DPS·공격 속도·치명타·생명력·보호막·방어도·회피·저항을 그대로 가져와 2D 스틱맨 전투로 돌려 봅니다.

- 16T 맵핑(10 / 25 / 50 / 100 / 200 / 300 / 500마리, 증폭 모드) 또는 우버 보스 5종(재의 중재자·크세쉬·안개 속의 왕·자로크·올로스)
- **대규모 무리는 순차 스폰** — 화면에는 최대 120마리만 세우고, 처치될 때마다 대기 중인 무리를 가장자리에서 채웁니다. 500마리도 그릴 목록이 120~150마리로 유지돼 프레임이 밀리지 않습니다.
- 메인 스킬 이름으로 이펙트를 자동 선택합니다: 얼음 화살(파편 부채꼴), 번개(연쇄 번개·낙뢰 기둥), 화염(2중 폭발 링), 근접(검기·충격파), 카오스(도트 오라), 소환수(미니언 타격).
- **메인 스킬 선택** 줄에는 불러온 빌드에 실제로 켜져 있는 **직접 쓰는 액티브 스킬**(한글명)이 피해가 큰 순서로 나오고, 하나를 고르면 그 스킬 하나로만 싸웁니다. 보조 젬·정신력 점유 젬·발동 장치(메타젬)·전령은 여기에 올리지 않습니다. 빌드를 바꾸거나 스킬을 끄면 줄도 그 빌드에 맞게 다시 만들어지고, 맨 앞 스킬이 기본 선택됩니다.
- 고른 스킬의 이름·이펙트·공격 속도·DPS가 그대로 전투에 쓰이고, 다른 스킬은 봇이 임의로 섞지 않습니다.
- 전투 화면 안에서 **정신력 젬과 메타 젬을 하나씩 켜고 끌 수 있습니다.** 끈 젬은 정신력 점유에서 빠지고 남은 예산으로 뒤 젬이 켜집니다. (전투 탭 위쪽의 수치 요약 글은 v1.1.4에서 걷어냈습니다.)
- 주력 그룹은 화면에서 고른 값이 없으면 PoB가 계산한 그룹(`mainSocketGroup`)과 그 안의 스킬 번호(`mainActiveSkill`)를 그대로 따릅니다.
- 마릿수·보스 칩과 달리 `피통·피해 증폭` 칩은 누를 때마다 켜짐/꺼짐이 뒤집힙니다(켜면 적 체력 1.8배·피해 1.4배).
- PoB가 DPS를 `inf`로 내보내는 빌드는 계산이 발산한 빌드입니다(두꺼비 폭발처럼 피해가 끝없이 되풀이되는 조합). 앱은 그 값을 4만대 추정치로 깎지 않고, poe.ninja가 보여 주는 것과 같은 **32비트 상한 2.1B**(2,147,483,647)로 표시합니다. 나머지 스킬은 평균 타격·공속·치명타에서 출발한 제 몫(보조 젬 수·젬 레벨·다단 히트 반영)으로 따로 잡아, 주력이 2.1B인 동안 다른 스킬은 10k·5.8k·1.6k처럼 수천~수만 대에 머뭅니다. 값이 추정이면 화면에 그렇게 적고, 10억 이상 수치는 `2.1B`처럼 B 단위로 표시합니다.
- 주력 스킬은 PoB `mainSocketGroup`·`mainActiveSkill`을 따르되, 그 그룹에 도이드리의 파멸이 들어 있으면 실제 피해 스킬인 **암울한 결과**로 잡습니다.
- 공격 속도에 맞춘 공격 모션, 치명타 화면 흔들림과 `CRIT!` 숫자, 처치 파편, 적 처치/사망 시 결과 요약(소요 시간·가한 피해·실전 DPS·치명타·피격/회피·생존율·사망 원인·스킬별 DPS)
- 점멸 타격·질풍·충전 지팡이처럼 적에게 붙는 순간이동 근접기는 걸어가지 않고, 공격할 때마다 적 옆으로 텔레포트해 벱니다. 지나온 자리에 푸른·금빛 잔상 2~3개와 섬광 선이 남습니다.
- 초당 4회를 넘는 고속 공속은 한 프레임에 여러 타를 누적해 타격이 씹히지 않고, 베기 궤적도 2~3겹으로 겹쳐 그립니다. (초당 30회까지 반영)
- 전투 중 1배속/2배속, 일시정지, 초기화

#### 관절 애니메이션

스틱맨은 막대기 하나가 아니라 **머리·몸통·상완/전완·허벅지/종아리·무기**를 따로 꺾는 관절 캐릭터입니다. `SkillPoses.kt`가 스킬마다 시전 키프레임을 들고 있어, 같은 근접기라도 동작이 다릅니다.

- 소용돌이 베기: 몸을 낮춰 크게 감아 돌며 360도로 벱니다 (몸통 회전 + 세 겹 검기)
- 돌개바람: 두 팔을 머리 위로 모아 내려친 뒤 크게 휘돌립니다
- 전기불꽃: 마법봉을 뒤로 눕혔다가 세 번 채찍처럼 튕깁니다
- 혜성: 두 손을 하늘로 치켜들었다가 땅으로 내리꽂고, 몸이 깊게 앉습니다
- 활 스킬: 시위를 눈까지 당겼다 놓고, 놓는 순간 뒷팔이 뒤로 빠집니다
- 저주·함성: 두 팔을 벌리고 고개를 젖힙니다

시전 초반에는 키프레임을 거의 그대로 쓰고, 막바지에만 서 있는 자세로 돌아가 동작이 뭉개지지 않습니다. 다리도 허벅지·종아리로 나뉘어 무릎이 꺾이므로, 앉아서 힘을 모으는 자세가 일직선으로 무너지지 않습니다.

- 공허의 형상: 근접기를 쓸 때마다 **반투명 보랏빛 상**이 플레이어 주위에 나타나, 그 스킬을 한 번 휘두르고 사라집니다. 상은 공허의 형상에 넣은 스킬을 그대로 따라 하며(예: 선회 공격), 권능 충전을 하나 쓰면 한 번에 3개가 나옵니다.
- 공허의 집중: 몇 초마다 실체 없는 종이 플레이어 주위에 생기고, 때리면 충격파가 터지며 권능 충전을 돌려줍니다.
- 콤보를 직접 짜 두면 전장 HUD에 지금 도는 순서(예: `소용돌이 베기 · 와류 2단계 → 돌개바람`)가 한 줄로 표시되고, 결과 요약에는 상·와류·돌개바람·종 횟수가 같이 적힙니다.

#### 메인 스킬 하나로 싸우기

전투 탭 위쪽 **메인 스킬 선택** 줄에서 고른 스킬 하나가 전투의 주력입니다.

- 고른 스킬의 모션·투사체·피해가 그대로 나가고, 빌드에 든 다른 액티브 스킬을 봇이 임의로 섞어 쓰지 않습니다
- 전령·정신력 점유 버프·메타(발동) 젬은 사용자가 켜 둔 것만 따로 작동합니다
- 스킬을 바꾸면 전투 중이어도 그 자리에서 새 스킬로 다시 시작합니다
- 준비 동작이 필요한 연계(소용돌이 베기 → 돌개바람, 연계 → 폭풍의 종 등)를 보고 싶으면 아래 **콤보 설정**에서 순서를 직접 짜면 됩니다

#### 콤보 설정

전투 탭의 **콤보 설정** 버튼을 누르면 시트가 열리고, 빌드에 장착된 스킬을 눌러 원하는 순서를 쌓을 수 있습니다.

- 목록에는 **빌드에 든 액티브·발동 스킬이 보조 젬만 빠진 채 전부** 나옵니다. 다른 스킬 세트에서 꺼 둔 그룹, 패시브 트리(공허의 형상 등)와 아이템(목걸이·부적의 부여 스킬)이 준 스킬, 아이템 설명에만 적힌 `Grants Skill`까지 포함합니다
- 같은 스킬을 여러 번 넣을 수 있습니다 (예: 소용돌이 베기 ×3 → 연발 사격 → 돌개바람)
- ↑ ↓ 로 순서를 바꾸고 ✕ 로 뺍니다. 처음에는 비어 있고, 직접 쌓은 순서만 전투에 씁니다
- 설정한 콤보는 기기에 저장되고, 전투 화면 위에 `직접 설정한 콤보: …`로, 전장 아래에 칩으로 표시됩니다. 지금 서 있는 칸만 밝게 켜집니다. 콤보를 비우면 위에서 고른 메인 스킬 하나만 씁니다
- 봇은 설정한 순서를 그대로 돌립니다. 폭풍의 종처럼 연계가 모자란 칸은 그 자리에서 기다리며 주력기로 연계를 채우고, 준비가 끝나면 다시 그 칸부터 이어 갑니다

#### 사망 화면과 스킬별 DPS

플레이어가 쓰러지면 전장이 그 자리에서 멈추고, 캐릭터가 무너지는 연출 위로 사망 원인과 스킬별 DPS 기록이 차례로 떠오릅니다.

- 쓰러짐 — 몸이 발을 축으로 옆으로 넘어가고, 붉은 충격파·파편·검은 연기가 터지며 몸에서 빠져나온 영혼이 위로 흩어집니다. 화면 가장자리가 붉게 어두워지고 마지막 한 방의 섬광이 한 번 번집니다
- 사망 원인 — 마지막으로 생명력을 깎은 한 방의 **공격자 · 기술 · 피해량 · 속성**을 적습니다 (`우버 자로크 · 번개 낙뢰 (피해 6,240)`). 최대 생명력의 80% 이상을 가져간 한 방은 `일격`으로 표시하고, 그 아래에 사망 직전 몇 초 동안 몇 대 맞아 얼마를 잃었는지 한 줄로 덧붙입니다
- 사망 원인은 모든 피해 경로에서 남습니다 — 보스의 기세 폭발·근접 강타·내려찍기·원거리 사격, 보스 패턴 장판(불기둥·유성 낙하·모래시계·룬 검기 등), 몬스터 투사체까지 각각 공격자 이름과 기술 이름이 붙습니다
- 스킬별 DPS 기록 — 주력기·콤보 스킬·메타젬 발동·전직 부여 스킬·소환수·기름 화염·점화까지 스킬 이름별로 누적 피해, 명중 횟수, 전투 시간 기준 실제 DPS, 전체 피해 대비 비율을 모아 내림차순으로 보여 줍니다. 비율만큼 막대가 차오르고, 화면에 들어가지 않는 줄은 `+ N개 스킬 더`로 접힙니다
- 카드는 배너 → 사망 원인 → 기록 줄 → 단추 순서로 **알파 0 → 1 페이드인**하며, 줄은 한 줄씩 시차를 두고 올라옵니다. 세로로 좁은 화면에서도 겹치지 않게 남은 높이에 들어가는 줄 수만 그리고, 그 계산은 화면 없이 단위 테스트로 확인합니다
- 카드 아래 **다시 시작**은 곧바로 같은 조건의 전투를 다시 돌이고, **닫기**는 카드만 걷어 전장을 그대로 둡니다. 전투 버튼(일시정지·초기화)은 그대로 살아 있습니다

#### 클리어 화면 (승리 연출과 스킬별 DPS)

맵핑의 마지막 적이나 보스를 처치해 무리를 다 쓸어버리면 전장이 그 자리에서 멈추고, 사망 화면과 대칭인 클리어 화면이 올라옵니다.

- 승리 연출 — 발밑에서 금빛·청백색 충격파가 두 겹으로 퍼지고, 빛기둥 세 줄기가 솟으며, 금빛 조각과 흰 불티가 위로 흩날립니다. 화면에 금빛 섬광이 한 번 번지고 `클리어`가 떠오릅니다
- 클리어 요약 — 배너에 전투 시간과 처치 수, 요약 카드에 총 입힌 피해·평균 DPS·가장 센 스킬과 그 비율이 적힙니다
- 스킬별 DPS 기록 — 사망 화면과 같은 목록을 같은 규칙으로 보여 줍니다. 스킬 이름별 누적 피해·명중 횟수·실전 DPS·비율을 내림차순으로 놓고 줄마다 비율 막대를 채우며, 화면에 들어가지 않는 줄은 `+ N개 스킬 더`로 접힙니다
- 배너 → 요약 → 기록 줄 → 단추 순서의 페이드인과 남은 높이에 맞춘 줄 수 계산은 `VictoryFx`에 모여 있고, 화면 없이 단위 테스트로 확인합니다
- 카드 아래 **다시 시작**은 같은 조건의 전투를 곧바로 다시 돌리고, **닫기**는 카드만 걷어 전장을 그대로 둡니다

#### 전령 (얼음 · 천둥 · 재)

PoB에 든 전령 젬을 읽어 전투 중 조건부로 발동시킵니다. 전령은 정신력을 점유하므로, 빌드의 정신력에서 소환수가 먼저 가져간 몫을 빼고 남는 만큼만 켭니다(전령 하나에 30).

- **얼음의 전령** — 동결됐거나 산산조각 난 적이 처치되면 그 자리에서 육각 서리 파동이 터지고 범위 안의 적이 냉기 피해를 받습니다
- **천둥의 전령** — 감전된 적이 처치되면 낙뢰 기둥이 떨어지고 주변 최대 4마리에게 번개가 연쇄합니다. 감전이 새로 걸릴 때마다(0.4초 간격) 그 적에게도 낙뢰 한 줄기가 내리칩니다
- **재의 전령** — 적이 처치되면 그 한 방의 초과 피해(생명력을 넘긴 몫)만큼 화염 폭발이 터지고 주변 적이 점화됩니다. 초과 피해가 없어도 타격의 30%는 태웁니다
- 전령 폭발 피해는 `얼음의 전령`처럼 전령 이름으로 스킬별 DPS 기록에 적립되므로, 기록 합계가 전체 피해와 어긋나지 않습니다. 같은 그룹에 물린 보조 젬은 피해와 광역을 키우고, 원소 집중을 물리면 상태이상을 걸지 못합니다
- 전장 HUD에 켜진 전령과 발동 횟수가, 결과 요약에 전령별 발동 횟수·피해가 적힙니다

#### 정신력 점유 버프 (정신력 젬)

poe2db의 Spirit Gems 53종을 점유량·효과 문장까지 받아 두고(assets/poe2_spirit_kr.json), PoB에서 켜 둔 젬을 찾아 전투에 반영합니다. 정신력 예산은 소환수 → 정신력 젬 → 전령 순서로 나눠 쓰고, 모자라면 뒤에 온 젬을 `꺼짐`으로 남겨 이유를 보여 줍니다. 장비(`Item:`)가 부여한 지속 버프도 목록에 올립니다.

- **수치 반영** — 회피·방어도·보호막·생명력·원소 저항·공격/시전 속도·치명타·재생·받는 피해 감소·피해 증폭이 전투 수치에 그대로 들어갑니다. 예) 바람의 무희 회피 +30%, 저항의 깃발 방어·회피 +30%, 전쟁 깃발 공격 피해 +25%·공속 +25%, 원소 융합 원소 피해 +49%, 희생 생명력 +100.
- **전투 연출** — 바람의 무희 피격 폭발(강풍의 힘), 혼의 춤 연막 보호막 회복, 껍질피부 방어, 한기의 방어구, 마그마 장벽 반격, 철의 수호 물리 피해 저장 폭발, 독성 운반자 중독 저장 폭발, 가시밭 가시 지대, 마름쇠(회피 시), 격노 중첩(야만적인 광분·광폭·영원한 격노), 소모(희귀·고유 적 접근 시간 증폭), 역병·피의 전령 처치 폭발.
- **화면** — 켜진 버프는 발밑 오라 고리로 색을 나눠 표시하고, 전투 HUD 한 줄과 결과 요약(버프별 발동 횟수·피해)에 적힙니다.
- 충전 운용과 겹치는 전투 격분·충전 조절은 충전 규칙에서 계산하므로 두 번 세지 않습니다.

#### 원소 이펙트와 상태이상

속성마다 투사체·착탄·상태이상을 다르게 그립니다.

- **번개** — 흰 코어 위에 푸른 전기, 가장자리에 보랏빛 글로우를 겹친 날카로운 지그재그 줄기가 내리꽂히고 중간에서 두세 갈래가 갈라집니다. 착탄점에서는 스파크 섬광이 사방으로 튑니다
- **불** — 흰 심·노란 몸통·붉은 열기로 겹친 화염구가 불혀를 흔들며 날아가고, 착탄하면 두 겹 폭발 링과 함께 불티가 솟고 검붉은 연기가 피어오릅니다
- **얼음** — 육각 결정 몸통에 고드름 촉을 단 얼음 화살과 결정이 뭉친 서리 보주가 서리 궤적을 남기고, 착탄하면 육각 결정이 퍼집니다
- **동결** — 얼어붙은 적은 걷지도 공격하지도 못하고, 몸을 감싼 반투명 육각 얼음 감옥에 서리 알갱이가 맺힙니다. 동결 상태로 처치되면 얼음 파편이 사방으로 튀는 **산산조각**이 터지고 시체가 얼음 가루로 흩어집니다. 얼음의 전령과 자연스럽게 이어집니다
- **감전** — 몸 위로 푸른-흰 전류가 지직거리고 받는 피해가 20% 늘어납니다. 감전 수치가 오르면 늘어나는 폭도 커져 최대 60%까지 오릅니다
- **점화** — 주황-붉은 불길이 일렁이며 매초 화염 피해가 들어가고, 그 피해는 `점화` DPS로 따로 적립됩니다

#### 충전 (권능 · 인내 · 격분)

전투 중 세 가지 충전을 실제로 쌓고 태웁니다. 빌드에 든 젬·패시브(키스톤 포함)·전직 노드·고유 아이템 글에서 충전 관련 문구를 읽어 규칙을 만듭니다.

- **전투 격분** — 빙결·전기 충격·속박을 걸 때마다 격분 충전을 하나 얻습니다. 젬 레벨에 따른 내부 쿨타임(20레벨 6.1초)을 지키므로 무한정 쌓이지 않습니다. 전투 모형에 아직 전기 충격·속박이 없어 **감전을 그 자리에 세웁니다**
- **공명** — 얻는 충전의 종류가 권능 → 인내 → 격분 → 권능으로 한 칸씩 돌아갑니다
- **충전 조절** — 유지 중이면 10초마다 세 충전을 하나씩 태우고, 그동안 권능이 있으면 치명타 확률, 인내가 있으면 받는 피해 감소, 격분이 있으면 공격 속도가 오릅니다
- 그 밖에 적 처치 시 격분, 피격 시 인내, 처치 시 충전 확률(고유 아이템), 치명타 시 권능, 살상 장법 마무리의 권능을 굴립니다. 최대 충전 수는 기본 3개이고 `최대 권능 충전 +1` 같은 문구를 읽어 늘립니다
- **기름 포화는 권능 충전을 하나도 남기지 않고 태웁니다** — 태운 수만큼 전기를 띤 기름 고리와 사방으로 터지는 전격 폭발이 붙어, 권능이 수급되는 동안 기름 폭격이 끊기지 않습니다
- 전장 HUD에 **권능(파랑) · 인내(빨강) · 격분(초록)** 알약이 나란히 뜨고, 결과 요약에도 마지막 충전 상태와 격분 획득·충전 소모 횟수가 적힙니다

#### 부적 변신과 기름 포화

PoE2에서 부적은 힘·지능을 요구하는 양손 근접 무기이고, 부적을 들고 있는 동안에는 그 형상(곰·늑대인간·와이번)으로 변신한 상태가 됩니다. 형상마다 쓸 수 있는 형태 변환 스킬이 다릅니다.

- 빌드의 무기 슬롯에 부적이 있거나, 형태 변환 스킬(기름 포화·사나운 발톱·십자 베기 등)이 주력이면 `Beasts.kt`가 형상을 판정합니다
- 전투가 시작되면 형상 오라가 터지고 스틱맨이 해당 야수로 변합니다. 곰은 앞발·턱·갈기, 늑대인간은 굽은 허리와 발톱·꼬리, 와이번은 날개·긴 목·꼬리를 관절로 움직입니다
- 기름 포화는 와이번으로 기름을 **360도 사방에 퍼붓습니다**. 바깥 고리 10발(추가 투사체만큼 더)이 화면을 둘러싸고, 권능 충전을 태우면 전기를 띤 보랏빛·연둣빛 기름 고리가 겹으로 더 날아갑니다. 떨어진 자리마다 기름 웅덩이가 생기고, 웅덩이는 옆 웅덩이로 불이 옮겨 붙어 연쇄 폭발합니다
- 기름 지대는 적을 20% 늦추고 노출(총 원소 저항 -20%)시킵니다. 점화된 적이나 폭발이 닿으면 불이 붙어 계속 타오릅니다
- 결과 요약에 변신 형상·기름 지대·점화 횟수·기름 피해가 함께 적힙니다

### 우버 보스 패턴

보스마다 인게임에서 쓰는 대표 스킬을 자기 패턴으로 씁니다. 체력 50% 이하에서 2페이즈로 넘어가고, 패턴이 강화됩니다.

| 보스 | 1페이즈 | 2페이즈 |
|---|---|---|
| 재의 중재자 | 화염 검기(직선 예고), 불기둥 | 심판의 안전지대(전장 폭발·가운데만 안전), 유성 낙하 |
| 균열 군주 크세쉬 | 균열 구체 연사, 거대 손 내려찍기 | 균열 쫄 소환 |
| 안개 속의 왕 | 의식 투사체, 순간이동 | 저주 장판(가운데만 안전한 고리), 분신 |
| 올로스 | 룬 검기, 빙결 파편 | 룬 보호막(피해 흡수), 광역 냉기 폭발 |
| 자로크 | 시간 구체, 모래시계(십자 예고) | 시간 왜곡, 번개 구슬 회전 |

- 스킬이 떨어지기 전에 바닥에 경고 장판(원·직선·고리·십자)이 차오르고, 안에 있으면 방어력·저항·회피로 계산한 실제 피해를 받습니다
- 플레이어는 장판이 떨어지기 직전 구르기로 빠져나갑니다
- 전장 HUD에 `P1/P2`와 지금 쓰는 패턴 이름이 표시됩니다
- 보스 5종은 각자의 실루엣(화염 후광·균열 팔·사슴뿔·룬 방패·모래시계)으로 그려집니다.
- 잔몹은 **검은 외곽선을 두른 괴물 실루엣**으로 다시 그렸습니다. 일반은 앞으로 굽은 뿔 달린 짐승, 마법은 떠 있는 후드 술사(보랏빛 눈·지팡이), 희귀는 날개·등 가시·갑주를 두른 거구(황금 왕관·오라)입니다. 눈은 붉거나 보랏빛으로 빛나 플레이어(밝은 뼈대)·소환수(뼈/유령)·반려수(네 발 짐승)와 한눈에 구분됩니다.

### 소환수 · 반려수

빌드에 소환수 젬이 있으면 전투에 실제로 세워 적을 쫓아가 때립니다.

- **해골 계열** — 전사·저격수·방화범·서리/폭풍 마법사·돌격병·강탈자·성직자. 부활하는 언데드라 죽으면 5초 뒤 다시 일어나고, 성직자는 주변 소환수를 고칩니다.
- **좀비·격노의 유령·망령** — 좀비는 20초 지속, 격노의 유령은 적이 지나쳐 가는 대신 빠르게 달려듭니다.
- **반려수** — 길들인 야수, 늑대 무리, 하이에나, 연무의 큰까마귀, 지옥불 사냥개, 야생 보호자(곰), 아즈메리 늑대, 로아. 네 발 짐승 실루엣과 금빛 목걸이로 소환수·몬스터와 구분됩니다.
- **정신력 점유** — 젬에 적힌 점유량을 합산해 `Spirit` 예산을 넘으면 마릿수를 줄이고 그 이유를 전투 탭에 적습니다.
- **어그로·피해 분담** — 적은 가까운 소환수를 72% 확률로 노리고, 근접·원거리 공격과 보스 광역기가 소환수에게도 들어갑니다.
- **소환수 사망 시 시전** — 소환수가 쓰러질 때마다 메타 에너지가 차서 연결된 주문이 발동합니다.
- 주력 스킬이 소환수 젬이면 PoB가 계산한 DPS를 소환수들이 나눠 갖고, 플레이어는 지원 동작만 합니다. 두꺼비처럼 다른 개체가 피해를 내는 빌드에서는 플레이어 평타 DPS를 따로 잡아 두 번 세지 않습니다.

### 암울한 결과 (Dark Consequences)

도이드리의 파멸(혈통 보조 젬)이 붙은 저주는 저주받은 지대를 만들고, 그 지대에서 0.25초마다 **마녀두꺼비**가 나옵니다(지대 하나에 4마리, 지대 2개까지).

- 두꺼비가 적에게 도약해 명중하면 **암울한 결과**가 발동해 1.6미터 폭발(카오스 피해)이 터집니다. 피해는 보조 대상 저주 젬의 레벨을 따릅니다(1레벨 5~10, 20레벨 186~345, 40레벨 3,246~6,029).
- PoB는 이 스킬의 DPS를 `inf`로 내보냅니다. 앱은 poe.ninja와 같이 그 값을 표시 상한 **2.1B**로 잡고, 전장에 저주받은 지대와 두꺼비를 그려 실제로 폭발시키며 폭발 횟수·피해를 결과에 적습니다. 두꺼비 한 번의 폭발 피해도 상한에 맞춰 커져서 16T 무리와 우버 보스가 한두 번의 폭발에 정리됩니다.
- PoB가 유한한 값을 주는 빌드에서는 `AverageHit`과 두꺼비 수·도약 주기로 초당 폭발 수를 어림합니다.
- 전투 탭 스킬 칩 맨 앞에 `암울한 결과`가 뜨고, 두꺼비 폭발은 소환수 피해로 따로 집계됩니다.

### 고유 아이템 효과

장착한 고유 아이템의 옵션 중 단일 타격 계산에 드러나지 않는 것을 `UniqueEffects.kt`가 읽어 전투에 넣습니다.

- 추가 투사체·연쇄, 피해의 일부를 다른 속성으로 얻기(`Gain 12% of Damage as Extra Fire Damage`), 명중 시 저주, 마무리 타격
- 처치 시 충전, 희귀 몬스터 처치 시 그 옵션 획득(헤드헌터), 주기적 성소 버프(신념의 망치), 재생
- 소환수 피해·생명력, 정신력, 접근 범위 2배
- 전투 탭에 `고유 효과 N개 · 아이템 이름…`과 대표 효과 3줄이 뜨고, 결과 요약에는 반영된 효과가 함께 남습니다.
- 생명력·저항·공격 속도처럼 PoB가 이미 계산한 수치는 다시 더하지 않고 목록에만 적습니다.

### 메타젬

PoB 2 빌드에 들어 있는 메타젬을 **전부** 인식해 전투에서 동시에 굴립니다. 첫 그룹만 쓰지 않습니다.

- 치명타 시 시전 · 감전 시 시전 · 빙결 시 시전 · 점화 시 시전 · 원소 상태이상 시 시전 · 원소 기원 · 소환수 사망 시 시전 · 피격 시 시전 · 기절 시 시전 · 회피 시 시전 · 근접 처치 시 시전
- 전령 4종(천둥·얼음·재·역병)과 신성모독
- 영문 이름·한글 이름·PoB `skillId` 모두로 판별합니다
- 적중할 때마다 치명타·감전·빙결·점화·처치·피격·회피 사건을 실제로 판정해 각 메타젬의 에너지를 채우고, 가득 차면 연결된 스킬(Comet·Arc·Fireball·Frost Bomb 등)이 이펙트와 피해로 발동합니다
- 전장 HUD와 결과 요약에 메타젬별 발동 횟수·피해량을 표시합니다

### 전직 패시브

PoB 빌드에 찍힌 전직 노드를 poe2db 트리 자료에서 찾아, 옵션을 두 갈래로 나눠 씁니다.

- **전투에 직접 반영** — 부여 스킬(공허의 형상·공허의 집중 등), 추가 투사체, 상태이상 확률·강도, 받는 피해 감폭과 물리 피해의 원소 전환, 보호막 재충전 지연·속도, 생명력 재생·흡수, 효과 범위, 메타 에너지
- 공허의 형상은 집중 유지가 아니라 **근접 공격에 반응**합니다. 플레이어가 근접기를 쓸 때마다 플레이어 주위 6미터 안에 상이 나타나, 형상에 넣은 근접기를 한 번 휘두르고 사라집니다. 상의 피해는 그 스킬의 80%이고, 권능 충전을 하나 쓰면 상이 2개 더 생깁니다(최대 3개).
- 공허의 집중은 노드에 적힌 대로 3초(재사용 대기시간 회복 반영)마다 종을 띄우고, 종을 때리면 충격파가 터지며 권능 충전이 돌아옵니다
- **PoB 수치에 이미 포함** — 생명력·에너지 보호막·방어도·회피·저항·치명타처럼 PoB가 계산해 넘긴 값은 다시 더하지 않고 목록에만 적습니다
- 전투 탭 머리말에 `전직 효과 N개 적용 · 주요 노드…`와 `전투 반영 N개`가 뜨고, 전장 HUD에도 금색 줄로 표시됩니다
- 전직별 노드 분석표는 `docs/ascendancy-effects.md`에 있습니다(전직 36종·노드 669개, 2026-11-23 자료)

수치는 PoB 기준값에 재생·보호막 충전·회피를 일반적인 값으로 가정한 간이 시각 시뮬레이션이며 실제 게임 판정과 다릅니다.

검색창은 이름, 영문 이름, 태그, 설명을 한 번에 훑습니다. 카드를 누르면 상세 웹뷰가 열리고, 웹뷰에는 모바일용 CSS를 넣어 상단 메뉴와 배너를 걷어 내고 넓은 표를 가로 스크롤로 감쌉니다.

### 메타 랭킹

PoB 탭의 **메타** 페이지는 리그 전직 점유율과 인기 빌드 DPS를 스냅샷으로 보여 줍니다.
poe.ninja 빌드 통계는 공개 API가 아니라 앱이 직접 받아오지 않고, U4N 티어리스트·PoB Archives에
공개된 값을 `Meta.kt`에 옮겨 두고 화면에 출처와 기준일을 함께 적습니다.
전직·스킬 이름은 게임 한국어 표기(poe2db.tw/kr)로 적고, DPS는 만 단위로 읽습니다.
poe.ninja 빌드 랭킹은 같은 페이지의 버튼으로 앱 안에서 실시간으로 열 수 있습니다.

### 장비 가치 (주얼·젬·플라스크 제외)

빌드를 불러오면 개요 카드 위쪽에 그 빌드의 장비 가치가 한 줄로 뜹니다.
`장비 가치 (주얼·젬·플라스크 제외): 약 12.3 디바인 (≈ 3,690 카옵)`처럼 적고,
누르면 부위별 내역과 산출 근거가 펼쳐집니다.

- 대상은 몸에 걸친 장비뿐입니다 — 무기 1·2(방패·화살통·부적 포함), 투구, 갑옷, 장갑, 장화, 목걸이, 반지 1·2, 허리띠. **주얼·젬·플라스크·호신부는 값에서 빠집니다**
- **고유 장비**는 poe.ninja의 PoE2 아이템 시세(실거래가)를 그대로 씁니다. 같은 이름의 매물이 여러 개면 타락하지 않은 쪽을 쓰고, 매물 수를 함께 적습니다
- **희귀·마법 장비**는 공식 거래소(trade2)에서 그 장비의 주요 옵션을 걸어 **비슷한 매물의 중위값**을 찾습니다. 값어치가 큰 옵션(모든 스킬 젬 레벨·생명력·에너지 보호막·정신력·저항·이동 속도·공격 속도·치명타·pDPS)을 최대 3개 고르고, 옵션 수치는 조금 낮춰 "비슷하거나 조금 나은" 매물을 봅니다
  - 거래소 검색은 로그인 없이도 되지만 호출 제한이 있어 한 번 산출에 3부위까지만 조회합니다. 조회하지 못한 부위는 **옵션 추정가**로 채우고, 화면에 그 사실을 적습니다
  - 기본형 이름을 거래소가 모르면 옵션만으로 한 번 더 찾습니다
- 옵션 추정가는 옵션 종류와 수치에 가중치를 매겨 계산합니다. pDPS/eDPS는 무기의 물리·원소 피해와 공격 속도에서 뽑습니다
- 환율은 poe.ninja 화폐 시세의 기준값(1 디바인 = ? 엑잘 / ? 카오스)을 그대로 씁니다. 환율을 못 받으면 디바인 값만 적습니다
- 근거는 부위마다 다르게 적습니다 — `(poe.ninja 실거래가)`, `(공식 거래소 유사 매물)`, `(옵션 추정가)`. 조회한 것처럼 보이게 적지 않습니다

### 장비창 (PoE2 인벤토리)

PoB 탭의 **장비** 페이지는 리스트 대신 게임과 같은 자리에 슬롯을 놓은 장비창입니다.

```
       [  투구  ] [목걸이]
[무기 1] [  갑옷  ] [무기 2]
[반지 1] [ 허리띠 ] [반지 2]
[ 장갑 ]           [ 장화 ]
```

- 각 칸에 아이템 아이콘을 깔고 등급(일반·마법·희귀·고유)에 맞춰 테두리 색을 바꿉니다.
- 아이콘을 한 번 탭하면 그 아이템의 이름·등급·베이스·옵션 패널이 격자 아래에 열리고,
  **같은 아이콘을 다시 탭하면 닫힙니다**. 다른 칸을 탭하면 그 칸 정보로 바뀝니다.
- 패널의 `장비 바꾸기`는 유니크 아이템을 검색해 그 슬롯에 끼우고, `초기화`는 원래 아이템으로 되돌립니다.
- 격자 아래에는 무기 교체·반지 3·부적·플라스크를 작은 칸으로 붙입니다.

## 빌드

JDK 17과 Android SDK 35가 필요합니다.

```bash
./gradlew assembleDebug      # app/build/outputs/apk/debug/app-debug.apk
./gradlew bundleRelease      # app/build/outputs/bundle/release/app-release.aab
```

`local.properties`에 SDK 경로를 적어 둡니다.

```properties
sdk.dir=/path/to/android-sdk
```

업로드 키는 `keystore/poe2db-upload.jks`에 있고, 루트의 `keystore.properties`를 읽어 서명합니다(둘 다 git 제외).
키가 없으면 릴리스 빌드는 디버그 키로 서명해 빌드만 통과시키므로, 배포 전에는 `scripts/create-release-keystore.md`를 확인하세요.

```bash
./gradlew bundleRelease
jarsigner -verify app/build/outputs/bundle/release/app-release.aab
```

스토어에 올릴 산출물은 `dist/`에 모아 둡니다.

```bash
dist/poe2db-kr-1.0.0-release-signed.aab   # 업로드 키로 서명한 AAB
dist/poe2db-kr-1.0.0-debug.apk            # 기기에 설치해 볼 APK
```

## 데이터 갱신

수록 자료는 `app/src/main/assets/poe2db_kr.json`에 들어 있습니다. 게임 패치로 수치가 바뀌면 다시 긁어서 앱을 새로 올립니다.

```bash
python3 scripts/fetch_poe2db.py        # poe2db.tw/kr 파싱 → assets JSON
python3 scripts/fetch_poe2_i18n.py     # 시세·장비 한글 사전 → assets/poe2_kr_i18n.json
python3 scripts/fetch_poe2_gems.py     # 스킬·보조 젬 한글 이름 → assets/poe2_kr_i18n.json
python3 scripts/fetch_poe2_tree.py     # 패시브 트리 노드·직업 이름·전직 부여 스킬 → assets/poe2_tree_kr.json
python3 scripts/make_ascendancy_doc.py # 전직 노드 분석표 → docs/ascendancy-effects.md
python3 scripts/make_store_assets.py   # 아이콘, 스토어 그래픽
python3 scripts/make_store_screenshots.py  # 스토어 스크린샷 5장
```

`fetch_poe2_i18n.py`는 poe.ninja 시세 응답의 영문 이름·옵션과 poe2db 한국어 페이지를 대조해
한글 이름 4,700여 개, 베이스 1,790여 개, 아이콘 3,880여 개, 옵션 문장 틀 1,880여 개를 만듭니다.
장비 옵션은 poe2db 분류 페이지(Modifiers Calc)의 영문판·한글판을 줄마다 짝지어 접사·에센스·
훼손·타락·룬·결속 문장을 모두 담고, 그 표에 없는 고유·플라스크·호신부 옵션은 고유 아이템
페이지의 두 언어 옵션을 대조해 채웁니다. `props`/`tags` 항목은 품질·방어도·요구 사항 같은
아이템 머리말과 `(implicit)`·`(crafted)` 꼬리표의 한글 표기입니다.
패치로 신규 아이템이 늘면 다시 돌려 사전을 갱신하세요 (`.cache/i18n/` 캐시).

`fetch_poe2_gems.py`는 poe2db의 스킬 젬·보조 젬·Spirit Gems 목록을 영문판·한국어판으로 짝지어
젬 이름 사전(1,060여 종)을 `poe2_kr_i18n.json`의 `gems`에 넣습니다. 지금 목록에 없는 예전 이름
(`Martial Tempo`, `Scattershot` 등 0.1 시절 보조 젬)은 웨이백 머신 사본에서 보탭니다.

`fetch_poe2_tree.py`는 poe2db 패시브 트리 자료(`data_kr.json`/`data_us.json`)에서 직업·전직 이름,
모든 노드의 한글 이름·설명·좌표, 연결선을 추려 700KB 남짓으로 만듭니다.
앱은 이 파일로 트리를 직접 그리고, PoB의 `Spec nodes` 목록을 poe2db 트리 주소로도 바꿉니다.

`fetch_poe2db.py`는 lxml만 있으면 됩니다. 내려받은 페이지는 `.cache/poe2db/`에 남아 다음 실행 때는 목록 페이지만 다시 받습니다. 젬 설명은 젬별 툴팁 조각을 한 번씩 더 받아 채웁니다.

## 배포

릴리스 AAB는 로컬에서 서명해 플레이스토어 콘솔에 직접 올립니다.

```bash
./gradlew bundleRelease
cp app/build/outputs/bundle/release/app-release.aab dist/poe2db-kr-1.0.0-release-signed.aab
jarsigner -verify dist/poe2db-kr-1.0.0-release-signed.aab
```

`versionCode`는 업로드할 때마다 `app/build.gradle.kts`에서 1씩 올립니다.
업로드 키와 비밀번호는 `keystore/`(git 제외)에만 두고, 저장소나 이슈에 적지 않습니다.
GitHub Actions로 빌드하려면 같은 값을 저장소 시크릿 `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`,
`KEY_ALIAS`, `KEY_PASSWORD`로 넣으면 됩니다.

## 고지

poe2db.tw와 Grinding Gear Games가 만든 공식 앱이 아닙니다. 게임 자료와 이미지의 권리는 원저작자에게 있고, 이 앱은 열람을 돕는 목적으로만 배포합니다. 삭제 요청이 오면 해당 자료를 내립니다.

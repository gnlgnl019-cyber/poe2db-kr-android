# 플레이스토어 등록 정보

## 앱 이름 (30자 이내)

```
PoE2DB KR - 패스 오브 엑자일 2 DB
```

## 간단한 설명 (80자 이내)

```
패스 오브 엑자일 2의 스킬 젬·유니크·화폐를 한글로 찾고, 실시간 시세와 PoB 실험실·전투 시뮬레이션까지 쓰는 DB 앱입니다.
```

## 자세한 설명

```
패스 오브 엑자일 2를 하면서 "이 젬 태그가 뭐였지", "이 유니크 옵션 수치가 얼마였지" 싶을 때 브라우저를 열고 광고를 지나며 표를 확대하던 일을 줄이려고 만든 앱입니다.

poe2db.tw 한국어 페이지의 자료를 미리 받아 앱 안에 넣어 두었습니다. 목록은 네트워크 없이도 바로 뜨고, 검색창에 한글 이름 일부만 입력해도 관련 항목이 걸립니다.

수록 자료 (2026년 11월 기준 4,354건)
- 스킬 젬 399개, 보조 젬 558개: 태그, 레벨 구간, 소모, 핵심 설명
- 유니크 아이템 463개: 부위, 기본 옵션, 고유 옵션 요약
- 무기 607개, 방어구 999개, 장신구 67개, 룬 213개
- 화폐 38종, 전직·직업 및 전직 패시브 244개
- 키워드 766개: 피해 유형, 상태 이상, 저주, 방어 등 용어 설명

DB
- 카드마다 원본 아이콘과 한글 이름, 영문 이름, 태그, 옵션 요약을 함께 보여 줍니다
- 상단 검색창에서 이름·태그·설명을 한 번에 걸러 냅니다
- 별표를 눌러 두면 즐겨찾기 탭에 모이고, 앱을 껐다 켜도 남아 있습니다
- 카드를 누르면 poe2db.tw의 원본 페이지를 모바일 화면에 맞춰 열어 줍니다. 표가 화면 밖으로 넘치지 않고, 상단 메뉴와 배너는 정리해서 보여 줍니다

시세
- poe.ninja 공개 시세를 화폐·룬·에센스·영혼 핵·조각·미가공 젬·징조·감정·기폭제와 고유 장비까지 종류별로 보여 줍니다
- 디바인·엑잘·카오스 환산 가격, 7일 변동률, 매물 수를 함께 적고 5분 동안 캐시합니다
- 아이콘·옵션을 내장 DB의 한글 표기로 맞춰 보여 줍니다

PoB 실험실
- Path of Building 공유 코드나 pobb.in 링크를 넣으면 스킬·장비·설정을 읽어 예상 DPS와 생명력·보호막·유효 체력을 계산합니다
- 장비를 바꿔 끼우거나 보조 젬 레벨, 인내·격분·권능 충전, 맹공, 적 유형과 상태 이상을 조절하면 바뀐 수치가 바로 반영됩니다
- 샘플 빌드로 코드 없이도 화면을 둘러볼 수 있습니다

전투 시뮬레이터
- 불러온 빌드의 수치 그대로 2D 스틱맨 전투를 돌려 봅니다
- 16T 맵핑(25·50·100마리, 피통·피해 증폭) 또는 우버 보스 5종과 싸웁니다
- 보스는 인게임 대표 스킬을 패턴으로 쓰고, 체력 절반에서 2페이즈로 넘어갑니다. 바닥 예고 장판을 피하지 못하면 방어력·저항·회피로 계산한 피해를 받습니다
- 메타젬(치명타 시 시전, 감전 시 시전 등)을 인식해 에너지가 차면 연결된 스킬이 발동합니다
- 결과 화면에 소요 시간, 가한 피해, 실전 DPS, 치명타·피격·회피 횟수, 생존율을 정리합니다

메타 랭킹
- 리그 전직 점유율과 인기 빌드의 DPS를 스냅샷으로 보여 주고, 기준일과 출처를 함께 적습니다
- poe.ninja 빌드 랭킹은 버튼 한 번으로 앱 안에서 실시간으로 열 수 있습니다

패시브 트리
- poe2db.tw의 패시브·아틀라스 트리 뷰어를 핀치 줌으로 봅니다

알아 두실 점
- poe2db.tw와 Grinding Gear Games가 만든 공식 앱이 아닙니다. 게임 자료와 이미지의 권리는 원저작자에게 있습니다
- 아이콘과 상세 페이지, 시세는 인터넷에서 불러오므로 연결이 없으면 글자와 내장 목록만 보입니다
- 전투 시뮬레이터와 PoB 계산은 입력한 빌드 수치를 바탕으로 한 간이 추정이며 게임 안의 실제 판정과 다를 수 있습니다
- 게임 패치로 수치가 바뀌면 앱을 새로 올려 자료를 갱신합니다

문의나 자료 삭제 요청은 스토어에 적힌 개발자 연락처로 보내 주세요.
```

## 등록 전에 챙길 것

1. 업로드 키로 서명한 AAB인지 확인한다. `dist/poe2db-kr-1.0.0-release-signed.aab` (별칭 `poe2db-upload`).
   키와 비밀번호는 `keystore/README_PRIVATE.txt` 에만 있고 저장소에는 올리지 않는다.
2. `applicationId`가 `com.sunuhwi.poe2dbkr`인지, `versionCode`가 이전 업로드보다 큰지 확인한다.
3. 개인정보 처리방침 URL을 GitHub Pages로 올린 `privacy-policy.html` 주소로 넣는다. 예: `https://gnlgnl019-cyber.github.io/poe2db-kr-android/privacy-policy.html`
4. 데이터 보안 양식은 "수집하는 데이터 없음"으로 답한다. 즐겨찾기와 최근 빌드는 기기 안에만 저장되고 전송되지 않는다.
5. 스크린샷은 위 5장을 올린다. 최소 2장이 필요하지만 기능을 골고루 보여 주려면 4~5장이 낫다.
6. 앱 콘텐츠 등급 설문에서 폭력성·공포 표현 여부를 게임 자료 이미지 기준으로 답한다. 잔혹한 묘사가 있는 아이콘이 일부 포함되어 있다.
7. 비공식 팬 앱이라는 점을 스토어 설명과 개인정보 처리방침 양쪽에 적어 둔다. 상표권 분쟁을 줄이는 가장 확실한 방법이다.
8. WebView만 감싼 앱으로 보이지 않도록, 오프라인 목록·검색·즐겨찾기·PoB 계산·전투 시뮬레이션 같은 자체 기능이 있다는 점을 설명에 분명히 적는다.

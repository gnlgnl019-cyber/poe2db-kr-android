# PoE2 전직 패시브 노드 분석과 시뮬레이터 적용

poe2db 한글 트리 자료(0.5, 2026-11-23)의 전직 노드를 전부 읽어 옵션을 분류한 표다. 앱의 `AscendancyEffects.kt`가 이 분류대로 전투 수치를 계산한다.

- 직업 12종 · 전직 36종 · 전직 노드 669개(시작 노드 36개 포함)
- 이 중 이름과 옵션이 공개된 노드 429개 · 미공개 빈 자리 240개
- 주요(전직 고유) 노드 207개 · 소형 노드 186개
- 전투 시뮬레이터가 직접 계산하는 노드 101개, 나머지는 PoB 수치에 이미 포함된 옵션

## 반영 방식

| 구분 | 뜻 | 처리 |
| --- | --- | --- |
| 시뮬 | PoB의 단일 타격 계산으로 드러나지 않는 효과 | 부여 스킬 발동, 추가 투사체, 상태이상 확률, 받는 피해 감폭·전환, 보호막 재충전·재생·흡수, 효과 범위, 메타 에너지 |
| PoB 합산 | 생명력·DPS·저항처럼 PoB가 이미 계산해 넘긴 수치 | 다시 더하지 않고 목록에만 표시 |
| 표시만 | 패시브 포인트, 룬 홈, 문구뿐인 효과 | 화면에만 표시 |
